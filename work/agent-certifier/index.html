Agent Certifier

Grading agent code without executing a line of it

Upload an AI agent codebase and get back a weighted score across security, stability, performance, informatics, compliance and ethics, from static analysis alone.

60 static-analysis tests
6 weighted categories
10 languages supported

Overview

Agent code fails in ways ordinary application code does not: prompt injection, unbounded tool loops, silent data exfiltration, missing human oversight. Those are review problems, and review does not scale.

Agent Certifier turns the review into a graded, repeatable artifact. It reads a codebase it did not author and returns a weighted score, a certification level, and a report naming what failed and why.

The scoring model

  • Security, 30%: injection, hardcoded secrets, prompt injection, data exfiltration, auth, input validation, dependencies, privilege escalation, information disclosure, LLM code injection.
  • Stability, 20%: error handling, infinite loops, unbounded recursion, resource leaks, timeouts, graceful degradation, state management, memory, concurrency, exception specificity.
  • Performance, 15%: caching, async I/O, batching, connection pooling, lazy loading, algorithmic complexity, streaming, rate limiting, resource cleanup, token optimization.
  • Informatics, 15%: complexity, documentation, modularity, type annotations, response format, logging, config externalization, API contracts, naming, duplication.
  • Compliance, 10%: PII handling, retention, audit logging, GDPR, licensing, terms of service, output filtering, consent, data minimization, regulatory awareness.
  • Ethics, 10%: bias detection, transparency, human oversight, refusal mechanisms, fairness, explainability, harm prevention, misinformation, manipulation, accountability.

Why static analysis

Nothing is executed. Running untrusted agent code to grade it would reproduce the exact class of risk the tool is looking for, so the analysis is pattern and heuristic based instead. That trades some recall for a guarantee that the grader cannot be turned into an attack surface, which is the right trade for a tool meant to be pointed at code you do not trust.

Engineering

  • Backend: FastAPI with async SQLAlchemy over SQLite, exposing OpenAPI docs.
  • Frontend: Next.js 14 with TypeScript and Tailwind, polling live test progress as a run proceeds.
  • Output: certification level from PLATINUM (90+) down through GOLD, SILVER and BRONZE to NOT_CERTIFIED, with a downloadable JSON report and a printable view.
  • Reach: ten languages: Python, JavaScript, TypeScript, Go, Java, Ruby, Rust, C++, C# and PHP.
  • Deployment: one docker compose up brings up both services.
