AIFORG

A Palantir-style operating layer for AI agents inside a business

AI for Organization: one agent platform for every employee in a company, grounded in the company’s own documents, gated by role, and built so raw PII never reaches a model.

2 hrs to integrate a new third-party tool
14 PII categories tokenized before any model call
5 role levels enforced on every retrieval

Overview

Companies want every employee using AI, and cannot let company data leak into external models to get there. AIFORG is the platform in between: deployed once by the company and used daily by everyone from an intern to the CEO. It knows the organization’s documents, knows each person’s role, and decides what every agent is allowed to see.

Underneath is a modular orchestration framework. Agents declare what they need, tools register what they offer, and the framework handles the handshake, so a new third-party tool joins in hours rather than weeks.

Access control and privacy

  • Auth: a FastAPI REST layer with JWT auth and RBAC/ABAC across five role levels, from basic user to executive.
  • Access-filtered RAG: retrieval over company documents in ChromaDB only returns chunks the requesting role may see.
  • PII tokenization: 14 categories of PII are tokenized before anything reaches the LLM gateway (Claude). This is enforced by the architecture, not by policy.
  • Audit log: every query and every document it touched is recorded.

Agent framework

  • Role-specific agents for analysis, audit, email and meeting notes.
  • Standardized agent interfaces define a common contract for any agent joining the system.
  • Dynamic tool registration lets new capabilities attach at runtime, without framework changes.
  • Plan, Reason, Act loops coordinate agents and tools through each task.
  • Google ADK and LangChain underneath, so existing agent ecosystems plug in rather than port over.

Results

  • Cut third-party agentic tool integration time to under 2 hours.
  • Zero raw PII reaches any model, and every interaction is auditable and exportable for compliance.
