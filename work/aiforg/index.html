AIFORG

A Palantir-style operating layer for AI agents inside a business

AI for Organization: one agent platform for every employee in a company, grounded in its own documents, gated by role, and built so raw PII never reaches a model.

2 hrs to integrate a new third-party tool
14 PII categories tokenized before any model call
5 role levels enforced on every retrieval

Overview

Companies want every employee using AI, and cannot let company data leak into external models to get there. AIFORG is the platform in between: deployed once by the company, used daily by everyone from an intern to the CEO. It knows the organization's documents, knows each person's role, and decides what every agent is allowed to see.

Underneath is a modular orchestration framework. Agents declare what they need, tools register what they offer, and the framework handles the handshake, so a new third-party tool joins in hours rather than weeks.

How it works

  • FastAPI REST layer with JWT auth and RBAC/ABAC across five role levels, from basic user to executive.
  • Access-filtered RAG over company documents in ChromaDB: retrieval only returns chunks the requesting role may see.
  • 14-category PII tokenization before anything reaches the LLM gateway (Claude), enforced by architecture rather than policy.
  • Role-specific agents for analysis, audit, email, and meeting notes, over a complete audit log of every query and document touched.
  • Standardized agent interfaces define a common contract for any agent joining the system.
  • Dynamic tool registration lets new capabilities attach at runtime, without framework changes.
  • Plan, Reason, Act execution loops coordinate agents and tools through each task.
  • Built on Google ADK and LangChain, so existing agent ecosystems plug in rather than port over.

Results

  • Cut third-party agentic tool integration time to under 2 hours.
  • Zero raw PII reaches any model; every interaction is auditable and exportable for compliance.
