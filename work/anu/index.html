ANU

Apple Swift Student Challenge 2026 winner, sole developer

A Swift-native iOS app that coordinates ten on-device agents through Apple Intelligence APIs, going as far as a phone can go before it needs the cloud.

10 coordinated on-device agents
50% fewer frontier API tokens
2026 Swift Student Challenge winner

Overview

ANU started from a simple question: how much of an AI assistant can run entirely on the device in your pocket? Most assistants send every request to a frontier model, which costs money, adds latency, and ships your data off the phone. ANU inverts that default.

I built it solo in Swift, and it won the Apple Swift Student Challenge 2026.

How it works

  • Ten specialized agents are orchestrated on top of Apple Intelligence APIs, each owning a slice of the assistant's behavior.
  • A CoreML routing layer classifies every user intent before any network call happens.
  • The majority of intents resolve locally on device; only genuinely high-complexity requests escalate to cloud frontier models.
  • The interface is SwiftUI end to end, designed so the local-first routing is invisible to the user.

Results

  • Won the Apple Swift Student Challenge 2026 as sole developer.
  • Cut frontier API token usage by 50% through on-device CoreML routing.
  • Resolved the majority of user intents locally, without a network round trip.
