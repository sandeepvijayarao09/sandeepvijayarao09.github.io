AutoFill Pro

A shipped Chrome extension for the worst part of job hunting

Fills job applications across 30+ ATS platforms from 44 locally stored profile fields, with an AI fallback only for the odd custom questions.

30+ ATS platforms supported
44 profile fields, stored locally
424 test cases

Overview

Anyone who has applied to jobs knows the loop: same resume, same fields, slightly different form, twenty minutes gone. AutoFill Pro pattern-matches those forms across Workday, Greenhouse, Lever, Taleo, iCIMS, and dozens of other ATS platforms and fills them instantly.

It is built privacy-first: sensitive fields like date of birth, EEOC responses, gender, and salary expectations never leave the device.

How it works

  • A local pattern-matching engine maps 44 profile fields onto each platform's form structure, no network call needed.
  • An AI fallback via NVIDIA NIM handles only free-form custom questions; everything standard fills locally.
  • Resume PDF import seeds the profile, and one-click undo reverses any fill.
  • Handles iframes, single-page apps, and character limits, and meets WCAG 2.1 AA accessibility.

Results

  • Works across 30+ ATS platforms, including Workday, Greenhouse, Lever, Taleo, and iCIMS.
  • 424 test cases covering platform quirks and edge cases.
  • Sensitive personal data is never transmitted off the device.
