Dual-LLM Personalization System

Called parallel to Google Omni by DeepMind researchers at Google I/O 2026

A three-layer router that learns which model each query deserves, sending the easy ones to a small model and the hard ones to a frontier LLM.

92.6% routing accuracy, 1000-case eval
85.3% of queries routed at zero API cost
14.7% cascade rate, down from 30.8%

Overview

Most queries sent to frontier LLMs don't need one. A question like "what's on my calendar" doesn't deserve the same model, latency, and cost as "compare these two research papers." This system makes that distinction automatically, per query, and was evaluated on 1,500 labeled cases.

At Google I/O 2026, DeepMind product and AI researchers independently recognized the routing architecture as parallel to Google Omni.

How it works

  • Layer 1 is a local TF-IDF plus logistic-regression router that classifies most queries instantly, at zero API cost.
  • Low-confidence queries fall back to a GPT-4o-mini JSON classifier before any answer is generated.
  • Simple queries are answered by GPT-4o-mini; only genuinely complex ones escalate to GPT-4o.
  • Persistent SQLite user profiles and sliding-window memory with rolling summaries personalize both paths.
  • Every routing decision is logged into a self-improving retraining loop, and a Streamlit UI exposes each routing choice transparently.

Results

  • 92.6% routing accuracy on a 1,000-case evaluation, with 0.885 precision, 0.963 recall, and 0.922 F1.
  • Cut the LLM cascade rate from 30.8% to 14.7%.
  • Routed 85.3% of queries with the local ML layer alone, at zero API cost.
  • Architecture recognized by DeepMind researchers at Google I/O 2026 as parallel to Google Omni.
