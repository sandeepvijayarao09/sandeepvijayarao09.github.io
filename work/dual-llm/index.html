Dual-LLM Personalization System

Called parallel to Google Omni by DeepMind researchers at Google I/O 2026

A dual-model router that classifies query complexity and dispatches each request to a lightweight local model or a frontier LLM.

92.6% routing accuracy
85.3% of queries served at zero cost
14.7% cascade rate, down from 30.8%

Overview

Most queries sent to frontier LLMs don't need one. A question like "what's on my calendar" doesn't deserve the same model, latency, and cost as "compare these two research papers." This system makes that distinction automatically, per query.

At Google I/O 2026, DeepMind product and AI researchers independently recognized the multimodal routing architecture as parallel to Google Omni.

How it works

  • A complexity classifier scores each incoming query and routes it to a lightweight on-device model or a frontier LLM.
  • Confidence gating decides when the local answer is good enough and when to cascade upward.
  • OpenCLIP embeddings extend routing to multimodal inputs, so images and text share one dispatch policy.
  • ChromaDB stores user context, letting the lightweight path personalize responses without touching the cloud.

Results

  • 92.6% routing accuracy on complexity classification.
  • Cut the LLM cascade rate from 30.8% to 14.7%.
  • Served 85.3% of all queries at zero API cost via on-device inference.
  • Architecture recognized by DeepMind researchers at Google I/O 2026 as parallel to Google Omni.
