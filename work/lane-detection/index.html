Real-time Lane Detection

Optimized for autonomous-driving edge hardware

A YOLOv8 lane segmentation model compressed with TensorRT INT8 until it ran at 150 frames per second on embedded GPUs.

99% detection accuracy
150 FPS on embedded GPU
80% faster than prior baseline

Overview

Lane detection models are easy to make accurate and hard to make fast. On autonomous-driving edge hardware the frame budget is brutal, and a model that misses it is useless no matter how accurate. This project chased both numbers at once.

How it works

  • A YOLOv8-based segmentation model is trained for lane geometry rather than generic objects.
  • TensorRT INT8 quantization compresses inference without giving back accuracy.
  • The pipeline is profiled and pruned end to end, targeting embedded GPU deployment from the start.

Results

  • 99% detection accuracy at 150 FPS on embedded GPU hardware.
  • Outperformed the prior baseline by 80% in inference speed at accuracy parity.
