Vision-Language Grounding

Zero-shot, open-vocabulary, no fine-tuning

OpenCLIP-based image-text grounding that hits 88% top-3 accuracy across open-vocabulary categories without a single category-specific training run.

88% top-3 accuracy, zero-shot
12 open-vocabulary categories
14% better cross-domain generalization

Overview

The interesting part of zero-shot grounding is what you don't do: no labels, no fine-tuning, no category list fixed in advance. The system grounds free-form text against images using embedding geometry alone, then gets measurably better with synthetic data.

How it works

  • OpenCLIP embeddings place images and text in a shared space, where grounding is nearest-neighbor search.
  • Cross-modal attention visualization exposes which image regions support each phrase.
  • Stable Diffusion generates synthetic training views, widening domain coverage without new photography.
  • An interactive Streamlit demo wraps the whole system for exploration.

Results

  • 88% top-3 accuracy across 12 open-vocabulary categories, fully zero-shot.
  • Improved cross-domain generalization by 14% with synthetic augmentation.
