Vision-Language Grounding

Zero-shot, open-vocabulary, no fine-tuning anywhere

Four pipelines for seeing how vision-language models think: CLIP grounding, cross-modal attention maps, diffusion generation, and embedding-space analysis.

4 multimodal pipelines
0 category-specific training runs

Overview

The interesting part of zero-shot grounding is what you don't do: no labels, no fine-tuning, no category list fixed in advance. This toolkit grounds free-form text against images using embedding geometry alone, then makes the model's reasoning visible.

How it works

  • CLIP ViT-B/32 embeddings, via OpenCLIP, place images and text in a shared space where grounding is nearest-neighbor search.
  • Cross-modal attention extraction and visualization expose which image regions support each phrase.
  • Stable Diffusion v1.5 serves as a generation backend for synthetic views.
  • Embedding-space analysis rounds it out: cosine similarity matrices and t-SNE or UMAP projections of the joint space.

Results

  • Grounds free-form text against images with no category-specific training.
  • Makes cross-modal attention inspectable, so model behavior can be debugged visually.
